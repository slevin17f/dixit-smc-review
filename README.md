# Dixit SMC Review

根据 Dixit Vekariya 的《Smart Money Concept (SMC) Trading Forex Market》整理的中文 Codex Skill。给它一段截至指定时刻的历史行情，便可按书中的规则核对多周期结构、供需区、入场条件和风险预算。九张能力卡各自标明参考页码，书中选例和合成练习分别标注。

## 安装

复制整个 `skills/dixit-smc-review` 目录至个人的 `~/.agents/skills/`，或项目中的 `.agents/skills/`。保留其中的 `SKILL.md` 与 `references/`。此技能仅使用 Markdown，无需额外依赖。
