# 决策规则速查 — Smart Money Concept (SMC) Trading Forex Market

| 能力 | 一句话规则 |
|---|---|
| 判读跨周期结构 | 先固定高低点与周期。第一次反向收盘突破后保留未确认状态，后续同向结构成立再更新趋势。 |
| 绘制并更新供需区 | 从快速离开并破坏结构的走势回溯起点，注明使用的画区方法、区域边界和首次重访。 |
| 复核流动性扫取 | 分别记录潜在订单聚集位置、穿越后的收盘与后续结构，保留未决状态。 |
| 筛选入场方式 | 先检查价格从哪一个区来，再问当前反应是否已破坏对侧结构。将候选入场与实际回踩分开记录。 |
| 从 H4 到 M1 复盘交易计划 | H4 定背景，M15 标未缓解区，M5 尝试缩小范围。若再细化产生多个明确未缓解区，退回最近的清晰周期。 |
| 核对入场的辅助证据 | 在高周期区域内分别记录基础形态、价格反应与指标方向，标记每条证据出现的时刻。 |
| 解读成交量分布 | 固定数据源和时间窗，找成交量最大的价档；分布高低和价值区高低分别标注。 |
| 重建斐波那契回撤 | 固定 A 对应 1、B 对应 0，用 B + r × (A − B) 计算价位，再检查价格到达后的确认。 |
| 审阅风险与执行纪律 | 从失效点和可承受金额倒推计划，填清止损、目标和管理规则。对照事前记录逐项评估执行。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
