# 读图术语与可观察证据

| 术语 | 在本书中的操作含义 | 页码 |
|---|---|---|
| SC / AOI / POI | 第2章用 SC 表示需要细化的候选位置。AOI、POI 指观察区域或兴趣点，记录周期及上下界才能跨图对应。 | 4–7、80 |
| IFC / imbalance | 快速单向移动留下的低效区，比较前后蜡烛影线覆盖；回踩是一种后续可能。 | 8–9、14–19 |
| OB / S/D | 订单块与供需区域定位推动的来源。第6章允许同向起点，第11章另有反向蜡烛及吞没偏好。 | 10–11、17、51–53 |
| mitigation | 价格首次触及未缓解的供需区即可更新为已缓解。区内是否填满、是否反转还需另记。 | 15 |
| BOS / BMS | 当前选定层级的结构突破；BMS 在第2章用于低周期确认。突破须写明参考摆动点。 | 5、48–50、75 |
| CHoCH / flip | CHoCH 指原有方向出现性质变化；flip 记录原控制区反应失败、随后被对侧击穿。二者可同现。 | 26–33、57–62 |
| EQH / EQL | 等高或等低，作为潜在流动性池标注。时段极值及趋势线也可成为候选。 | 12–13、53–56 |
| 弱高 / 弱低 | 在作者的延续假设中，先前未能导致反向结构突破的极值可作为目标。 | 55–56、78–79 |
| VSR | 需求区的快速 V 形反应或供给区的倒 V 反应；书中未给统一速度阈值。 | 63 |
| 溢价 / 折扣 | 以选定结构腿作参照定位价格高低；更换锚点会改变含义。 | 66–68、78–83 |
| POC / VA | 指定样本里成交量最大的价档、成交集中区。Profile High/Low 是样本成交过的最高/最低价格。 | 86–89 |
| R | 以单笔初始计划风险为一单位记录盈亏，分批退出按实际仓位比例核算。 | 60–72、105–107 |
