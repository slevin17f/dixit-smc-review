# Dixit Vekariya 的 SMC 图表复盘法

《Smart Money Concept (SMC) Trading Forex Market》，封面署名 Dixit Vekariya，年份 2025 据所给文件名。以下页码均从 PDF 封面计。全书 107 页，第 18 章结语与第 17 章末段同在末页。

作者试图回答一个实际问题：价格进入预画区域后，哪些新证据足以改变对市场方向、入场方式或退出位置的判断？

| 章节 | 原书的论证与用途 |
|---|---|
| 1–5 · pp.3–13 | 从冲动入场切入，比较直接挂单和等待确认。用不平衡、订单块和高低点解释为什么某些位置值得观察。 |
| 6–10 · pp.14–47 | 追踪区域从形成到触及、被突破或翻转的过程。H4 到 M1 的计划把这些判据放回时间顺序。 |
| 11–12 · pp.48–83 | 在主波段与内部结构间切换，规定宏观突破的收盘判据。再用 V 形反应、背离、溢折价复查形态。 |
| 13–14 · pp.84–100 | 分别按成交价位和推动段长度定位参考价。两种数据可以落在相近位置，各自需要独立输入。 |
| 15–18 · pp.101–107 | 用检查单、单笔风险和退出管理把方法落实到记录；结语回到纪律与资金管理。 |

第 2 页列明交易风险。文中证据以带注解的选图和叙述为主。价格路径可以核对，参与者身份、订单规模和必然回补无法由 K 线直接观察。书中盈利案例缺少完整取样区间、失败样本与统一成本口径，不能据此计算策略期望值。第 104 页风险次数的例子也混用了不同基数。

## 复盘任务

| 任务 | 页码 | 交付与核查理由 |
|---|---|---|
| 判读跨周期结构 | 48–53、73–83 | 先固定高低点与周期。第一次反向收盘突破后保留未确认状态，后续同向结构成立再更新趋势。 |
| 绘制并更新供需区 | 8–11、14–21、51–53 | 从快速离开并破坏结构的走势回溯起点，注明使用的画区方法、区域边界和首次重访。 |
| 复核流动性扫取 | 12–13、44–46、53–57 | 分别记录潜在订单聚集位置、穿越后的收盘与后续结构，保留未决状态。 |
| 筛选入场方式 | 4–7、22–36、57–62 | 先检查价格从哪一个区来，再问当前反应是否已破坏对侧结构。将候选入场与实际回踩分开记录。 |
| 从 H4 到 M1 复盘交易计划 | 37–43、80–81、101 | H4 定背景，M15 标未缓解区，M5 尝试缩小范围。若再细化产生多个明确未缓解区，退回最近的清晰周期。 |
| 核对入场的辅助证据 | 57–72 | 在高周期区域内分别记录基础形态、价格反应与指标方向，标记每条证据出现的时刻。 |
| 解读成交量分布 | 84–89 | 固定数据源和时间窗，找成交量最大的价档；分布高低和价值区高低分别标注。 |
| 重建斐波那契回撤 | 90–100 | 固定 A 对应 1、B 对应 0，用 B + r × (A − B) 计算价位，再检查价格到达后的确认。 |
| 审阅风险与执行纪律 | 68–72、101–107 | 从失效点和可承受金额倒推计划，填清止损、目标和管理规则。对照事前记录逐项评估执行。 |
